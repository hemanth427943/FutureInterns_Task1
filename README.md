# Business Sales Performance Analytics Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes sales performance using the Superstore dataset.  
It highlights key metrics such as total sales, profit, and quantity, along with trends and regional insights.

## 🧠 Key Insights
- Technology category contributes the highest profit.
- South region shows declining sales in Q3.
- Office Supplies have high volume but low margin.

## 🛠️ Tools Used
- Power BI Desktop
- Microsoft Excel (for data cleaning)
- GitHub (for version control)
